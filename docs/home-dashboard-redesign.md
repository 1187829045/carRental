# 登录后首页改版说明

## 目标
- 将登录后的默认工作台从传统表格页升级为现代化信息门户。
- 保持现有系统菜单结构、`.action` 路由风格和 iframe 标签页机制不变。
- 优先展示欢迎信息、业务概览、快捷入口、推荐模块和动态信息。

## 桌面端设计稿说明
- 顶部区域：左侧为欢迎横幅，包含时间、问候语和两个主操作按钮；右侧为用户信息卡，显示用户名、角色、快捷入口数量和推荐数量。
- 第二层区域：四个业务概览卡片，展示系统用户数、车辆数、客户数、出租订单数。
- 第三层区域：
  - 左侧为快捷操作、系统公告、最新留言。
  - 右侧为个性化推荐和使用建议。
- 视觉风格：蓝白渐变主视觉、圆角卡片、轻阴影、统一信息层级和分组留白。

## 移动端设计稿说明
- 主视觉区域改为单列纵向堆叠，优先显示欢迎语与当前时间。
- 概览卡片由四列变为一列或两列，根据屏幕宽度自适应。
- 快捷入口和推荐卡片在窄屏下自动改为单列，保证点击区域充足。
- 列表模块保留公告与留言，但内容宽度自适应，不要求横向滚动。

## 已实现内容
- 响应式 HTML/CSS 工作台页面
- 欢迎区与用户信息区
- 业务概览卡片
- 快捷操作入口
- 个性化推荐模块
- 公告与留言动态列表
- 平滑淡入动画与 hover 交互

- Chrome 最新版
- Edge 最新版
- Safari 16+

## UAT 验收清单
- 登录成功后默认进入新工作台页面。
- 欢迎区显示当前用户名和实时时间。
- 快捷操作点击后能正常在父级标签页中打开业务页面。
- 系统用户数、车辆数、客户数、出租订单数能正确显示。
- 公告与留言可正常加载，点击后可查看详情。
- 在平板和手机尺寸下页面无明显错位，卡片可自然换行。
- 页面首次打开无明显卡顿，接口加载失败时有空态提示。
